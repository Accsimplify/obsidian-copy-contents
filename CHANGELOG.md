# Changelog

## 1.0.3

- Add searchable declarative settings for Obsidian 1.13 and later while
  retaining the existing settings tab for Obsidian 1.12.
- Add validation for numeric settings and file-extension filters.
- Document that clipboard access is write-only, user-triggered, and local.

## 1.0.2

- Restore a reproducible TypeScript build from the published plugin.
- Resolve cancelled file-selection dialogs cleanly.
- Preserve nested paths when copying or exporting folders.
- Fix timestamped export conflict names.
- Prevent old exports from being included in new folder exports.
- Correct fenced-code handling in plain text output.
- Normalize export paths and filenames.
- Add automated tests, validation, CI, and draft release creation.

## 1.0.1

- Update plugin metadata and documentation.

## 1.0.0

- Initial release.
