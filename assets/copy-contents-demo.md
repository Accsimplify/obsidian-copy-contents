# Copy Contents demonstration

The GIF shows the real Copy Contents 1.0.3 plugin in Obsidian 1.14.5 on Windows, using a disposable vault containing three synthetic notes about a community garden workshop.

The sequence was captured on 29 October 2026: an empty destination, the folder context menu, the file-selection dialog, the focused destination, and the actual pasted output. The animation is assembled from those five UI captures, with pauses shortened to six seconds. It is not a continuous real-time recording. No UI or note content was generated to simulate plugin behavior.

Settings: Markdown output, file names and folder heading included, selection dialog enabled, threshold set to two eligible files. All three notes were selected. No personal vault content is included.

Asset: `copy-contents-demo.gif`; 1000 x 768 pixels; 60 frames at 10 fps; 6.00 seconds; loops continuously. Verified by decoding representative frames and checking the saved paste result. This is desktop smoke-test evidence, not mobile coverage.
